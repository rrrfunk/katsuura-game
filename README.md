# にゃんと多忙な勝浦朝市

勝浦朝市を舞台に、看板猫のミケを操作して朝市へ乱入する敵から店通りを守る、Canvasベースのアクションゲームです。朝市・猫・カツオ・タンデム自転車・神輿の既存素材と演出を生かし、攻撃は自動、プレイヤーは移動に集中する作りです。

## 遊び方

- アイテムは約3〜4.2秒ごとに出現し、3秒以内に拾うと次の出現まで最大1.4秒へ短縮。援護で道を開きながら次の品物を回収します。
- 敵を倒すと経験値を獲得し、レベルアップ時に攻撃や能力が自動で強化されます。通知はミケ付近の「LVUP!」と約0.7秒の発光だけで、移動・戦闘は止まりません。
- 約70秒で巨大キョン王、約120秒で最終ボスの暴走族総長が登場します。時間が来ただけではクリアにならず、総長を倒すと勝利です。
- アイテムは吸い寄せられず、ミケが触れたときに回収します。わらび餅のノラは近くをジグザグに走って包囲を崩し、コーヒーのタンデムはミケの向いている左右の方向へ細い道を開き、タンタン麺の神輿は広い範囲を押し返します。
- スケーターとトンビは頭上の「！」と構える動きで攻撃を予告します。スケーターは直線突進、トンビは狙った場所へ急降下し、予告後は照準を追い直しません。横へよけて、攻撃後の隙を使います。
- 45秒以降は大群12秒・立て直し6秒を繰り返します。立て直し中は新たな敵が出現せず、通常敵の追跡が少し遅くなります。
- 遊び方を開いている間は戦闘が一時停止します。プレイ中に「タイトルへ戻る」を選ぶと戦闘を終了してタイトルへ戻ります。

平和時間を待たずに始めるには、画面左下の「バトルへ」を押します。戦闘開始時点まで進み、敵の登場演出へ切り替わります。

## 操作

**PC**：WASDまたは矢印キーで移動します。マウスは左ボタンを押したままドラッグして移動できます。ShiftまたはSpaceを押している間は移動が速くなります。

**スマートフォン**：横向きで遊びます。右下のジョイスティックに触れてからドラッグして移動します。小さく倒すとゆっくり、大きく倒すと走り、指を離すと止まります。縦向きにすると戦闘が停止し、横へ戻した後は「続ける」を押して再開します。

敵・助っ人のカットインは自動で閉じません。画面または続行ボタンをタップして進めます（PCはクリック・Enter・Spaceも対応）。待っている間は戦闘時間・敵の動きを止め、連続する助っ人は1枚ずつ入力を待ちます。

## スマートフォンの表示

ブラウザの可視領域に合わせてゲーム画面を広げます。全画面操作ボタンはありません。ホーム画面へ追加したWebアプリの起動は別途実機確認してください。

## 起動

`index.html`を対応ブラウザで開くと遊べます。iPhone実機でホーム画面へ追加して試す場合は、HTTPSでアクセスできる配信環境を使い、Chromeの共有メニューから追加してください。公開・配信先の設定はこのリポジトリには含まれていません。

## スマートフォンUIの保守

- `js/mobile-ui.js`：可視領域へのカメラ調整、簡易HUD、一時停止メニュー。戦闘処理は`js/game.js`。
- `mobile.css`：スマートフォン専用レイアウト。PC用CSSへスマホの上書きを重ねない。
- 設計値は`DESIGN_RULES.md`、見本は`DESIGN_GUIDE.html`。横画面ではHP・レベル・残り時間・一時停止のみ常時表示する。
- `assets/nora_run.webp`は格闘ノラネコの透過4コマ走行シート。12コマ/秒で再生し、街路をジグザグに走る。素材仕様は`assets/nora_run.prompt.md`。
- `js/balance.js`：敵の波、アイテム間隔、援護の上限・強さを集約。`js/peace-scene.js`：平和時間の接近会話。
- `js/enemy-tactics.js`：敵の予告・突進・急降下と頭上の予告表示。進行はゲーム時間に統一し、一時停止中は動かさない。

## 検証

`node tests/game-regression.cjs`で被弾・援護・画面遷移・音声復帰の回帰テストを実行する。
`node tests/balance-simulation.cjs`で6種類の固定乱数を使い、回収を優先する自動操作と回収しない自動操作を比較する。描画を省略した参考値であり、人のクリア率・実機FPSではない。

ローカル確認は`node server.js`。スマホ横（852×330、667×280）、縦回転、メニュー・遊び方・結果をブラウザで確認する。iPhone Safari/Chrome実機のバー伸縮・ホーム画面起動は、デスクトップ上のエミュレーションと別の検証項目とする。

平和BGMは `assets/bgm_peace.m4a`。元の朝市メロディを `scripts/build-peace-bgm.cjs` でWAV化し、macOSの `afconvert -f m4af -d 'aac ' -b 64000` でAACへ変換する。BGMは同じHTMLAudioを使い、カットイン終了では曲を先頭へ戻さない。
