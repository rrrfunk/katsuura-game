# 『勝浦朝市サバイバー！〜看板猫ミケの敵薙ぎ払い大乱闘〜』

千葉県勝浦市の名物「勝浦朝市（下本町通り・遠見岬神社前）」を舞台にした、16-bitレトロ調の**ダダサバイバー（Survivor.io / Vampire Survivors）風 爽快ローグライトアクションゲーム**です。
朝市の看板三毛猫「ミケ」となり、乱入してきたヤンキー軍団、房総名物のキョンの群れ、上空のトンビをオート爪撃やカツオブーメランで薙ぎ倒します！

---

## 🎮 遊び方・操作方法

### 基本ルール
- **攻撃はフルオート（自動攻撃）**！プレイヤーは敵の攻撃を避けて移動しながら小判を回収！
- 敵を倒すとドロップする**小判（EXP）**を集めるとレベルアップ！
- レベルアップごとに**3枚のスキル強化カード**から好きな武器・能力を選んでミケを強化！
- 敵から時折ドロップする**勝浦名物アイテム**（カツオ・SPICE COFFEE・わらび餅）を拾ってHP回復＆超強力バフを発動！
- 3分間生き延びて勝浦朝市の平和を取り戻そう！

### 操作方法（PC）
- **移動**：`WASD` または `矢印キー`
- **緊急回避ダッシュ**：`Shift` キー（スタミナ消費で無敵高速ダッシュ）
- **必殺猫爪ラッシュ（手動連射）**：`Space` キー（進行方向へ強力な爪撃3連発）
- **全方位ニャー威嚇咆哮**：`C` キー（周囲360度の敵を一網打尽にノックバック＆気絶）

### 操作方法（スマートフォン・タブレット）
- 画面下の **バーチャル十字キー（▲▼◀▶）** で移動
- 画面右下の各ボタン：
  - **Spaceボタン**：必殺猫爪ラッシュ
  - **DASH / Shiftボタン**：緊急回避ダッシュ
  - **Cボタン**：全方位ニャー威嚇咆哮

1. 🐾 **三毛猫の爪撃**：最も近い敵へ鋭い爪撃波を自動発射！レベルUPで多方向同時攻撃！
2. 🐟 **勝浦カツオブーメラン**：ミケの周囲を高速回転しながら広がり、敵をまとめて貫通！
3. 📢 **ニャー威嚇衝撃波**：一定間隔で画面いっぱいに音波リングを放ち、敵を吹き飛ばす！
4. 🔥 **炭火七輪ファイア**：前方に炭火の火の粉を撒き散らし、敵を炎上継続ダメージ！
5. ⚡ **韋駄天キャット**：移動速度アップ！
6. 🧲 **マグネットヒゲ**：小判・回復アイテムの吸引範囲が広がる！
7. 🥫 **頑丈な極上猫缶**：最大HPが増加し、毎秒HPが自動回復！
8. ☕ **SPICEドリップ**：全スキルの攻撃力アップ＆クールダウン短縮！

3. **上空の鳶（トンビ）**：

4. **巨大ボス**：
