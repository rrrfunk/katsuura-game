# 勝浦朝市サバイバー

勝浦朝市を舞台に、看板猫のミケを操作して朝市へ乱入する敵から店通りを守る、Canvasベースのアクションゲームです。朝市・猫・カツオ・タンデム自転車・神輿の既存素材と演出を生かし、攻撃は自動、プレイヤーは移動に集中する作りです。

## 遊び方

- 敵を倒すと経験値を獲得し、レベルアップ時に攻撃や能力が自動で強化されます。
- 約70秒で巨大キョン王、約120秒で最終ボスの暴走族総長が登場します。時間が来ただけではクリアにならず、総長を倒すと勝利です。
- 敵が落とす朝市アイテムには、移動速度が上がりタンデム自転車が走るコーヒー、シールドと助太刀猫が出るわらび餅、神輿が敵をなぎ倒す勝浦タンタン麺があります。
- 遊び方を開いている間は戦闘が一時停止します。プレイ中に「タイトルへ戻る」を選ぶと戦闘を終了してタイトルへ戻ります。

## 操作

**PC**：WASDまたは矢印キーで移動します。マウスは左ボタンを押したままドラッグして移動できます。ShiftまたはSpaceを押している間は移動が速くなります。

**スマートフォン**：横向きで遊びます。画面右下のジョイスティックで移動します。縦向きにすると戦闘が停止し、横へ戻した後は「続ける」を押して再開します。

## 全画面とiPhone Chrome

タイトルまたはゲーム画面の「全画面」から、ブラウザが対応していれば全画面表示を試せます。通常タブではブラウザ側の仕様によりバーを隠せない場合があります。その場合はChromeの共有メニューから「ホーム画面に追加」し、追加したアイコンからWebアプリとして開けるか試してください。Webアプリとして利用できる場合にホーム画面のショートカットから起動する方法は[Chrome公式ヘルプ](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DiOS&hl=ja)を参照してください。iPhone実機でのインストール・表示は別途確認が必要です。

## 起動

`index.html`を対応ブラウザで開くと遊べます。iPhone実機でホーム画面へ追加して試す場合は、HTTPSでアクセスできる配信環境を使い、Chromeの共有メニューから追加してください。公開・配信先の設定はこのリポジトリには含まれていません。

開発時の変更状況、確認済みのテスト、未確認事項は [`outputs/PDCA_REPORT.md`](outputs/PDCA_REPORT.md) にまとめています。
